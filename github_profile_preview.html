📋 How to set this up on GitHub

Step 1: Go to your github.com/tanikush/tanikush repo
Step 2: Replace README.md with the README.md file provided
Step 3: Upload hero.svg to the same repo root
Step 4 (Important): Add your actual photo! Upload a square PNG as my-photo.png to the repo.
In hero.svg, replace the "TK" avatar circle with:
<image href="my-photo.png" x="490" y="110" width="160" height="160" clip-path="url(#avatarClip)"/>

In this HTML preview, replace both TK text nodes inside .person-avatar and .avatar-inner with:
<img src="your-photo.jpg" alt="Tanisha"/>
